# Lições por domínio

Um arquivo por domínio, criado sob demanda. Registrar aqui toda correção do usuário
durante uma tarefa — padrões e antipadrões que devem sobreviver à sessão.

- `audio.md` — ffmpeg, medição de energia, transcrição, separação, pitch, quantização
- `exportadores.md` — GP5/MusicXML, round-trip de formato binário
- `navegador.md` — verificação de página no navegador (headless, CDP, alphaTab)
- `workflow.md` — meta-regras de processo (herdadas do global) + port de estímulo/medição
